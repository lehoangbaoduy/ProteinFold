# ProteinFold

This repository compares a **genetic algorithm (GA)**, **ant colony optimization (ACO)** and
**probability-based particle swarm optimization (PSO)** on the **HP lattice protein-folding
problem**, in 2D, with 3D as an extension. It is a graduate course project for EECS 6180 at
the University of Toledo.

A protein is a string of H (hydrophobic) and P (polar) residues. A fold places the chain
on a square or cubic lattice without overlaps. Its energy is −1 for every pair of H beads
that touch on the lattice but are not neighbours in the chain. The algorithms **search**
for low-energy folds; nothing is trained in advance.

The repository contains:

- **`src/hpfold/`**: the core package (standard library and numpy only).
  - The HP model, valid-fold generation and repair.
  - GA, ACO and PSO behind one `run()` contract, with an exact evaluation budget.
  - The JSON entry point used by the webpage.
- **`src/hpfold_tools/`**: the experiment runner, statistics (Mann-Whitney with Holm
  correction, Vargha–Delaney A₁₂, Friedman), figures, LaTeX tables, and exports for the
  webpage.
- **`data/benchmarks.json`**: 21 benchmark sequences from the literature, each with its
  source. See [docs/benchmarks_sources.md](docs/benchmarks_sources.md).
- **`configs/`** and **`results/`**: the experiment configurations and their raw results.
  Every figure and table is generated by a script.
- **`web/`**: a static webpage that runs the same Python code in the browser through
  Pyodide. You enter a sequence and watch GA, ACO and PSO fold it live. It is still in
  progress.

The full specification is [docs/PRD.md](docs/PRD.md). Progress and design decisions are
logged in [docs/progress.md](docs/progress.md).

## Quick start

Requirements: Python 3.12 or newer with [uv](https://docs.astral.sh/uv/), and Node 20 or
newer with npm 11 for the webpage.

```bash
uv sync                                   # install Python dependencies
make check                                # tests, coverage >= 90%, ruff, bandit, pip-audit

# experiments (resumable; rows are appended as runs finish)
uv run python -m hpfold_tools.experiments configs/main_2d.toml --workers 8
make figures tables                       # regenerate figures and LaTeX tables from results/

# webpage
npm --prefix web ci
make web-runtime                          # self-hosted Pyodide + hpfold bundle into web/public/
make web-data                             # experiment data for the paper-results tab
npm --prefix web test
```

Example of one run from Python:

```python
from hpfold.algorithms import ALGORITHMS

aco = ALGORITHMS["ACO"]
result = aco.run("HPHPPHHPHPPHPHHPPHPH", dim=2, params=aco.Params(), seed=1, budget=8000)
print(result.best_energy, result.best_moves)
```

## Reproducibility

- **Seeding:** every run is seeded, and the same seed gives the same result.
- **Equal budgets:** all three algorithms get exactly the same number of fitness
  evaluations.
- **NA:** a run that finds no valid fold reports NA, never 0.
- **Browser parity:** the browser solver reproduces native results exactly. This is
  checked against [tests/fixtures/web_golden.json](tests/fixtures/web_golden.json).
