# Benchmark sources and verification notes

Data file: [`data/benchmarks.json`](../data/benchmarks.json) (spec `PFOLD-DATA-001`, PRD FR-B1–B5).

## Sources
| Key | Citation | Full text used |
|---|---|---|
| `thachuk2007` | Thachuk C, Shmygelska A, Hoos HH. *A replica exchange Monte Carlo algorithm for protein folding in the HP model.* BMC Bioinformatics 2007;8:342. doi:10.1186/1471-2105-8-342 | [PMC2071922](https://pmc.ncbi.nlm.nih.gov/articles/PMC2071922/), Table 1 "Standard benchmark sequences" |
| `shmygelska2005` | Shmygelska A, Hoos HH. *An ant colony optimisation algorithm for the 2D and 3D hydrophobic polar protein folding problem.* BMC Bioinformatics 2005;6:30. doi:10.1186/1471-2105-6-30 | [PMC555464](https://pmc.ncbi.nlm.nih.gov/articles/PMC555464/), Table 1 "2D and 3D HP standard benchmark instances" |

Original provenance, per the Shmygelska & Hoos 2005 Table 1 caption: most instances are from the "HP Benchmarks" collection hosted by Sandia National Laboratories (their ref. [44]); S1-9 is from König & Dandekar 1999 (ref. [45]). The caption says "the last two instances (2D) are from [21]" (Ramakrishnan et al. 1997), but the last two rows of that table are 3D (S2-9, S2-10). Because the caption is ambiguous, no instance here is attributed to [21].

## How the data was produced
1. Both papers' Table 1 were transcribed from the PMC HTML, keeping the printed compressed notation (e.g. `H2(P2H)7H`).
2. A script expanded the notation (`Hi` = i consecutive H; `(s)i` = i repetitions of s) and checked each expansion against the stated length.
3. The two sources were compared instance by instance.
4. `data/benchmarks.json` was generated by script from the Thachuk et al. 2007 notation. No sequence was typed out by hand.
5. The code reviewer independently parsed Table 1 from the Europe PMC full-text XML of both papers and confirmed that all 21 instances match Thachuk et al. 2007 on id, length, E\*, notation and expanded sequence.
6. `tests/test_benchmarks.py` pins the verified (id, length, E\*, SHA-256 of sequence) values, and also re-checks each entry: an independent expander, the alphabet, the length, cited sources, and a physical upper bound on |E\*|. The bound uses lattice bipartiteness: |E\*| ≤ 2·min(H_even, H_odd) + 2 in 2D and 4·min(H_even, H_odd) + 2 in 3D.

## Cross-check results
- All 21 instances (11 in 2D, 10 in 3D) have identical E\* in both papers.
- 17 of 21 notations are identical verbatim. Of the other 4, 2 are real mismatches in the 2005 source (S1-6, S2-1), and 2 are rendering anomalies that match 2007 once interpreted (S1-11, S2-3). These were confirmed by an independent parse of both papers' Europe PMC full-text XML during code review:

| ID | Finding | Resolution |
|---|---|---|
| S1-6 | The 2005 notation `H2(PH)3PH4PH(P3H)2P4H(P3H)2PHPH4(HP)3H2` expands to **51** residues, but the stated length is 50 | Use the 2007 notation, which expands to exactly 50 |
| S2-1 | The 2005 notation reads `…P2HPH2PHPH2…`, which expands to **47** residues against a stated 48; 2007 has `…P2HPH3PHPH2…` | Use the 2007 notation, which expands to exactly 48 |
| S1-11 | The 2005 HTML shows a lowercase `p11` | Read as `P11`; it then matches 2007 exactly |
| S2-3 | The 2005 HTML/XML has an H carrying a subscript P (`H<sub>P</sub>`), a mispositioned `HP` | Read as `HP`; it then equals 2007. The 2007 notation is used |

It is not determined whether the two 2005 discrepancies are typos in the paper or artifacts of the PMC HTML rendering. Either way the 2005 versions are inconsistent with their own stated lengths.

## Energy semantics
Both papers report E\* as the optimal or best known energy, without marking which values are proven optima. All entries are therefore stored with `energy_kind = "best_known"`. "Success" in the experiments means reaching E\* (PRD FR-A1, FR-B4).

## Not included (possible later additions)
Thachuk et al. 2007 also report biological/designed instances (B50-5, B50-7, D-1, D-2) and stable Z-, L0- and L1-structures. Their sequences are only in that paper's Additional file 1, which was not transcribed, so they are not part of this dataset.
